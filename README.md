# Зоряний клас (Star Class)

Веб-застосунок (PWA) для вчителя та учнів, що реалізує ігрову економіку в класі: учні отримують **зірки ✦** за оцінки та міняють їх на нагороди (смаколики, привілеї).

Застосунок розроблено з пріоритетом на приватність (без зберігання персональних даних, лише вигадані псевдоніми та UUID) та простоту використання.

## Основні можливості

- **Панель вчителя:** Швидке зарахування зірок за оцінки через вбудований сканер QR-кодів.
- **Профіль учня:** Застосунок (PWA) для дитини, де вона може перевіряти свій баланс, історію нарахувань та прогрес до наступного рівня без необхідності авторизації — просто за допомогою персоналізованого посилання, яке зберігається на пристрої.
- **Магазин нагород:** Каталог нагород із розрахунком прогресу (скільки ще зірок потрібно для покупки).
- **Адміністрування:** Зручна панель для додавання нагород, відстеження бюджету, створення нових профілів та генерації аркуша формату А4 з QR-картками учнів.
- **Бюджет та прогнозування:** Інструменти для розрахунку витрат вчителя на нагороди протягом навчального року.

## Технологічний стек

- **Frontend:** Vanilla HTML, CSS, JavaScript (ES-модулі). Без транспайлерів та бандлерів.
- **Backend:** Firebase (Firestore та Authentication) — тарифний план Spark (безкоштовний).
- **PWA:** Service Worker для офлайн-доступу та кешування статики. Можливість встановлення на головний екран телефону (iOS/Android).
- **Хостинг:** GitHub Pages для фронтенду.

## Як розгорнути

1. **Створіть Firebase проєкт**
   - Увімкніть **Authentication** (наприклад, Вхід через Google).
   - Увімкніть **Firestore Database**.
   - Додайте веб-застосунок у Firebase та скопіюйте конфігурацію в `src/data/firebase.js`.
   
2. **Налаштуйте Firestore Rules**
   - Скопіюйте правила безпеки (firestore.rules) у ваш Firebase проєкт, щоб забезпечити доступ лише авторизованому вчителю.

3. **Створіть акаунт вчителя**
   - Зайдіть у застосунок та авторизуйтеся через Google.
   - Візьміть свій Firebase UID та створіть документ у колекції `admins/{ваш-uid}` у Firestore, щоб надати собі права адміністратора.

4. **Завантажте базову конфігурацію**
   - Створіть документ `config/published` з налаштуваннями магазину та квестів (або скористайтеся функцією ініціалізації в коді).

5. **Розгортання на GitHub Pages**
   - Запуште код у ваш репозиторій GitHub та увімкніть GitHub Pages у налаштуваннях репозиторію.

## Експлуатація та резервні копії

У розділі "Адміністрування" вчитель має доступ до:
- **Експорту бази даних:** Завантаження поточного стану всіх учнів та журналу транзакцій у форматі JSON.
- **Імпорту бази даних:** Відновлення з бекапу.
- **Перевірки цілісності:** Аудит бази даних для пошуку розбіжностей у балансі.
- **Закриття навчального року:** Скидання балансів і підготовка системи до нового навчального року з відзначенням перехідних залишків.
