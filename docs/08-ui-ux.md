# 08. UI/UX

## 1. Принципи

- Дитина розуміє екран за 5 секунд: одне велике число (баланс) і три смуги прогресу.
- Вчитель виконує дію за один скан і 1–2 дотики; жодних діалогів підтвердження для видачі (є скасування).
- Mobile-first (учень 360–430 px; вчитель телефон, планшет або ноутбук).
- Мова українська; ніяких «магічних» чисел у коді, усі тексти з `src/i18n/uk.js`.
- Без випадковості, без рейтингів, без порівнянь між дітьми.

## 2. Візуальна тема «зоряна ніч»

**Токени (`styles/tokens.css`):**

| Токен | Темна (за замовчуванням) | Світла |
|---|---|---|
| `--bg` | `#0e1230` | `#f6f7ff` |
| `--surface` | `#181d45` | `#ffffff` |
| `--text` | `#f2f4ff` | `#171a3a` |
| `--muted` | `#a9b0e0` | `#5a608f` |
| `--star` | `#ffc53d` | `#d99100` |
| `--accent` | `#8b7bff` | `#5b48e8` |
| `--ok` | `#3ddc97` | `#138a5a` |
| `--danger` | `#ff6b6b` | `#c43838` |

Темна/світла тема за `prefers-color-scheme` з ручним перемикачем. Контраст тексту ≥ 4,5:1 (перевірити).

**Типографіка:** системні шрифти (`system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`), без зовнішніх шрифтів. Розміри: баланс 56–72 px, заголовки 20–24 px, текст 16 px.

**Іконка ✦ (SVG-символ):**

```html
<svg width="0" height="0" style="position:absolute"><symbol id="star" viewBox="0 0 24 24">
  <path d="M12 2C12.6 7.5 16.5 11.4 22 12C16.5 12.6 12.6 16.5 12 22C11.4 16.5 7.5 12.6 2 12C7.5 11.4 11.4 7.5 12 2Z"/>
</symbol></svg>
<!-- використання --> <svg class="star" aria-hidden="true"><use href="#star"/></svg>
```

Колір `fill: var(--star)`. У друкованих матеріалах і сповіщеннях використовується текстовий символ ✦ (U+2726).

**Рух:** лічильник балансу «докручується» (≈ 600 мс); квитанція виїжджає знизу. При `prefers-reduced-motion` анімацій немає, лише миттєва зміна.

**Кольори рівнів нагород:** карамель (теплий оранжевий), желейка (аметист), тарталетка (золото) плюс іконки 🍬🍮🥧, щоб не залежати від кольору.

## 3. Екрани учня (`index.html`, PWA)

Навігація внизу: **Мої ✦ · Мій QR · Магазин · Квести · Історія**.

### 3.1. Мої ✦ (головний)

```
┌──────────────────────────────┐
│  Лис-07          Рівень 3    │
│  ✦ 23                        │   ← велике число, анімація при зміні
│  Сузір'я  ▓▓▓▓▓░░░  до 4: 57 │
├──────────────────────────────┤
│ 🍬 Карамель      7 ✦   [✓]   │
│ 🍮 Желейка      12 ✦   [✓]   │
│ 🥧 Тарталетка   17 ✦   [✓]   │
│    прогрес-бар до кожної     │
│    або «ще 4 ✦» / «через 12  │
│    днів»                     │
├──────────────────────────────┤
│ 📈 Зростання 1/2  🔥 0/2      │
└──────────────────────────────┘
```

Вимоги: баланс і прогрес оновлюються в реальному часі; для кожної нагороди статус: можна взяти / «ще N ✦» / «знову через N днів» / «закінчилось»; відлік до кінця року, коли лишається ≤ 14 днів.

### 3.2. Мій QR

Великий QR (`P`), псевдонім, підказка «Збільши яскравість». Працює офлайн.

### 3.3. Магазин

Список активних позицій (іконка, назва, ціна, статус). Кнопка «Показати вчителю» для доступної позиції генерує QR `R` (дійсний сьогодні).

### 3.4. Квести

Картки квестів: назва, умова простими словами, прогрес у цьому місяці, скільки ✦ можна ще отримати («Ліміт квестів: 5/8 ✦»). Для «Активного тижня»: «2 з 3 оцінок за 7 днів».

### 3.5. Історія

Останні 20 подій: «+8 ✦ за оцінки», «🍬 −7 ✦», «+3 ✦ Зростання», «↩ скасовано». Без показу оцінок поштучно за замовчуванням (лише суму).

### 3.6. Квитанція

Тост після події: «+8 ✦» або «Отримано 🍬 −7 ✦, залишок 16 ✦»; зникає за 5 с; `aria-live="polite"`.

### 3.7. Службове

Перший запуск: короткий екран «Привіт, Лис-07!» і пропозиція додати на головний екран. Кнопка «Це не я» (очищає збережений профіль). Офлайн: сірий банер «Немає зв'язку, показано останній баланс».

## 4. Екрани вчителя (`teacher/index.html`)

### 4.1. Вхід

Email/пароль (або Google). Стан «Немає доступу», якщо користувача немає в `admins`.

### 4.2. Сканер (головний)

```
┌──────────────────────────────────────┐
│  [ вікно камери  ]       [🔦]        │
│  Наведи на QR учня                   │
│  [Вибрати учня зі списку]            │
│  Підказки: бекап · 3 учні з 17 ✦ ... │
└──────────────────────────────────────┘
```

### 4.3. Панель учня

```
┌──────────────────────────────────────────────┐
│ 🦊 Лис-07   (І. К.)                    23 ✦  │   ← ініціали з локальної довідки (за наявності)
├──────────────────────────────────────────────┤
│ Оцінки:  [7] [8] [9] [10] [11] [12]          │   ← кнопки з cfg.grades
│ Вибрано: 11, 9  →  +8 ✦  (+3 ✦ «Зростання»)  │   ← попередній розрахунок
│                [  Зарахувати  ]              │
├──────────────────────────────────────────────┤
│ Нагорода: [🍬 7 ✦] [🍮 12 ✦] [🥧 ще 17 ✦]    │   ← недоступні сірі з причиною
│ Внесок:   [🤝 +2 ✦]                          │
├──────────────────────────────────────────────┤
│        [ Наступний учень ]                   │
└──────────────────────────────────────────────┘
```

Поведінка: після «Зарахувати» панель лишається відкритою для видачі; тап на нагороді = списання без діалогу; знизу «Видано 🍬 −7 ✦ · Скасувати (10 с)»; через 60 с бездіяльності або «Наступний» повернення до сканера; м'яке застереження про повтор; підпис «Не забудьте розписатись у щоденнику» ненав'язливо після зарахування.

Для замовлення (`R`): панель відкривається з вибраною позицією, головна кнопка «Видати 🍬 −7 ✦».

### 4.4. Список учнів

Таблиця: псевдонім, (ініціали з довідки), баланс, рівень; пошук; фільтр «Показати архівовані»; дії: відкрити панель, друк картки, коригування, перевипуск, архівація.

### 4.5. Адмінпанель

Екрани перелічені в `09-admin-panel.md`.

## 5. Тексти (приклади для `i18n/uk.js`)

| Ключ | Текст |
|---|---|
| `scan.unknown` | Це не картка Зоряного класу |
| `scan.noCamera` | Немає доступу до камери. Дозволь камеру в налаштуваннях браузера або вибери учня зі списку |
| `order.expired` | Замовлення не на сьогодні |
| `credit.done` | Зараховано +{n} ✦ |
| `credit.repeat` | Щойно вже зараховували {g}. Підтвердити ще раз? |
| `redeem.done` | Видано {item} −{n} ✦ |
| `redeem.insufficient` | Ще {n} ✦ |
| `redeem.cooldown` | Знову через {days} дн. |
| `redeem.stock` | Закінчилось |
| `offline.teacher` | Немає зв'язку, спробуйте ще раз |
| `undo` | Скасувати |
| `receipt.credit` | +{n} ✦ |
| `receipt.redeem` | Отримано {item} −{n} ✦, залишок {left} ✦ |
| `year.countdown` | До кінця року {days} дн. Залишок {n} ✦: встигни обміняти |

Відмінювання: `plural(n, ['зірка','зірки','зірок'])`, `plural(days, ['день','дні','днів'])`. Не конкатенувати вручну.

## 6. Доступність

- Цілі дотику ≥ 48×48 px; відстань між кнопками ≥ 8 px.
- Не лише колір: іконки й текстові статуси.
- `aria-live="polite"` для балансу й квитанції; `aria-label` для іконок; фокус-кільця.
- Усі функції вчителя доступні з клавіатури (десктоп).
- Контраст ≥ 4,5:1; `prefers-reduced-motion` поважається; `prefers-color-scheme`.
- Мінімальний розмір тексту 16 px; масштабування сторінки не блокується.

## 7. Стани

Для кожного екрана реалізувати: завантаження (скелетон), порожній стан, помилка мережі (з кнопкою «Повторити»), офлайн (банер), «немає доступу». Помилки для дитини прості й добрі («Щось пішло не так. Спробуй ще раз»), для вчителя конкретні.
