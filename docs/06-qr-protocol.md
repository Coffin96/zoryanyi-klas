# 06. QR: протокол, сканер, друк карток

## 1. Принцип

QR **ідентифікує профіль** і, за потреби, передає **замовлення нагороди**. Він **не містить оцінок** і нічого не нараховує сам. Доказом оцінки лишається щоденник із підписом вчителя. Сесій і «з'єднань» немає: кожен скан одноразова дія. Це гарантує, що підроблений QR шкоди не завдасть.

## 2. Типи

| Тип | Де показується | Вміст |
|---|---|---|
| **Картка (URL)** | друкована картка | `https://<адреса>/#/p/<uuid>` (відкривається камерою телефона; також читається сканером вчителя) |
| **`P`** | вкладка учня «Мій QR» | `KR1\|P\|<uuid>` |
| **`R`** | вкладка учня «Магазин → Показати вчителю» | `KR1\|R\|<uuid>\|<id>\|<itemId>.<qty>\|<YYMMDD>` |

`id` це 8 випадкових символів base36 (`crypto.getRandomValues`). `YYMMDD` це київська дата створення; замовлення дійсне лише в цей день. Ціна, баланс, ліміти й запас **беруться з бази**, не з QR.

## 3. Кодек

```js
// src/qr/protocol.js
const V = 'KR1';
const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/;
const URL_CARD = /#\/p\/([0-9a-f-]{36})\/?$/;

export const encodeP = uuid => `${V}|P|${uuid}`;
export const encodeR = (uuid, id, item, qty, ymd) => `${V}|R|${uuid}|${id}|${item}.${qty}|${ymd}`;

export function decode(text) {
  const t = String(text).trim();
  const m = t.match(URL_CARD);
  if (m && UUID.test(m[1])) return { type: 'card', uuid: m[1] };
  const [v, kind, uuid, id, body, ymd] = t.split('|');
  if (v !== V || !UUID.test(uuid ?? '')) throw new Error('bad-qr');
  if (kind === 'P') return { type: 'card', uuid };
  if (kind === 'R') {
    const [item, qty] = (body ?? '').split('.');
    const q = Number(qty);
    if (!/^[a-z0-9_]{2,24}$/.test(item ?? '') || !Number.isInteger(q) || q < 1 || q > 10 || !/^\d{6}$/.test(ymd ?? ''))
      throw new Error('bad-qr');
    return { type: 'order', uuid, id, item, qty: q, ymd };
  }
  throw new Error('bad-qr');
}
```

**Тести:** обидва формати картки; `P`; `R` коректний; `R` з неправильним `qty`/`item`/датою; чужий текст; порожній рядок; UUID не v4; URL з іншим хешем.

## 4. Сканер (`src/qr/scanner.js`)

**Вимоги:**

1. Камера: `navigator.mediaDevices.getUserMedia({ video: { facingMode: 'environment' } })` (потрібен HTTPS; `localhost` для розробки).
2. Декодування: якщо є `BarcodeDetector` і підтримується формат `qr_code`, використовувати його; інакше `jsQR` на кадрі `<canvas>` (знижена частота кадрів, 8–10 разів на секунду, зменшена роздільність для швидкості).
3. Дебаунс: після успішного скану ігнорувати той самий вміст 1,5 с; після відкриття панелі сканер ставиться на паузу.
4. Зворотний зв'язок: вібрація (`navigator.vibrate`, де підтримується) і короткий візуальний сигнал; без звуку за замовчуванням.
5. Кнопка ліхтарика, якщо камера підтримує `torch`.
6. Обробка помилок з українськими повідомленнями: немає дозволу на камеру (інструкція, як дозволити), камери немає, невідомий QR («Це не картка Зоряного класу»), застаріле замовлення («Замовлення не на сьогодні»).
7. Запасний шлях завжди на екрані: «Вибрати учня зі списку».
8. Зупиняти потік камери при виході з екрана (економія батареї, приватність).

**Продуктивність:** час від наведення до відкриття панелі ≲ 2 с на сучасному телефоні.

## 5. Генерація (`src/qr/render.js`)

- Бібліотека `qrcode-generator` (локально в `vendor/`), рівень корекції помилок **M**.
- Відображення: SVG або `<canvas>`; тихі поля ≥ 4 модулі; розмір на екрані ≥ 250 px, на друкованій картці ≥ 35 мм.
- Вкладка «Мій QR»: великий QR + псевдонім + підказка «Збільши яскравість екрана» (веб не може сам змінити яскравість).
- Працює офлайн (генерація локальна).

## 6. Друковані картки

- A4, 6–8 карток на аркуш, `@media print` у `styles/print.css`.
- Вміст картки: QR (URL-формат), псевдонім великим шрифтом, коротка підказка «Покажи цей QR вчителю». **Ніяких імен.**
- Кнопка «Друк» у «Учні → Друк карток» (вибір усіх або окремих профілів).
- Нова картка при перевипуску посилання (S11).

## 7. Безпека

QR на картці це непідбираємий ідентифікатор; хто його сфотографував, може лише переглянути баланс (див. `05-security-privacy.md`). Витрата вимагає присутності й дії вчителя. Тип `R` не містить цін, лише ідентифікатор позиції, тому підроблений `R` лише відкриє панель з вибраною позицією, яку вчитель може не видати.
